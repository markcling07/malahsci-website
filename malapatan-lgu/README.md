# Municipality of Malapatan Website (Concept)

A sample one-page website for the Municipality of Malapatan, Sarangani Province.

Built with plain HTML, CSS and JavaScript, so no build step is needed.

This is **not** the official LGU website. The emblem in `images/` is a placeholder, not the town seal. Before publishing, replace it with the official seal and confirm all details with the Municipal Government.

## Files

- `index.html`: page content (about, barangays, officials, services, tourism, contact)
- `styles.css`: design and layout
- `script.js`: mobile menu, auto-hiding header, Philippine Standard Time clock and barangay search/sort
- `images/`: placeholder emblem and favicon

## Sources

- Population: Philippine Statistics Authority, 2020 and 2024 censuses (via [PhilAtlas](https://www.philatlas.com/mindanao/r12/sarangani/malapatan.html) and [Wikipedia](https://en.wikipedia.org/wiki/Malapatan))
- Creation of the town: Republic Act No. 5823 (June 21, 1969)
- Officials: [Wikipedia](https://en.wikipedia.org/wiki/Malapatan). Check these with the LGU, since they change after elections.
- Festival and crafts: news reports on the Pakaradyan Festival and Blaan weaving
