# Malapatan College of Science and Technology (MalahSCI) Website

A sample one-page website for Malapatan College of Science and Technology (MalahSCI), Malapatan, Sarangani.

Built with plain HTML, CSS and JavaScript, so no build step is needed.

## Files

- `index.html`: page content
- `styles.css`: design and layout
- `script.js`: mobile menu, auto-hiding header, program carousel, gallery lightbox and inquiry form
- `images/`: logo, campus picture and event photos from the official [MalahSCI Facebook page](https://www.facebook.com/MalahSCI)

## View it locally

Open `index.html` in a browser.
