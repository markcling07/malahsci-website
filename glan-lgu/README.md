# Municipality of Glan Website (Concept)

A sample one-page website for the Municipality of Glan, Sarangani Province.

Built with plain HTML, CSS and JavaScript, so no build step is needed.

This is **not** the official LGU website. Get the Municipal Government's approval and confirm all details with them before publishing it anywhere.

## Files

- `index.html`: page content (about, barangays, officials, services, earthquake recovery, tourism, contact)
- `styles.css`: design and layout
- `script.js`: mobile menu, auto-hiding header, Philippine Standard Time clock and barangay search/sort
- `images/emblem.svg`: an original concept emblem (sun over the bay). It is **not** the official town seal. The official seal on Wikipedia is marked non-free, so ask the LGU for a copy and permission to use it.

## Sources

- Population: Philippine Statistics Authority, 2020 and 2024 censuses (via [PhilAtlas](https://www.philatlas.com/mindanao/r12/sarangani/glan.html) and [Wikipedia](https://en.wikipedia.org/wiki/Glan,_Sarangani))
- Land area: 610.30 km² per Wikipedia. PhilAtlas lists 533.51 km², so confirm the official figure with the LGU.
- History: Executive Order No. 250 (July 27, 1949); settlement of Agricultural Colony No. 9 (October 8, 1914)
- Officials: [Wikipedia](https://en.wikipedia.org/wiki/Glan,_Sarangani). Check these with the LGU.
- Tourism: news reports on Gumasa Beach, SarBay Fest and Glan's heritage houses (BusinessMirror, Inquirer, PIA)
- Earthquake: news reports on the June 8, 2026 M7.8 earthquake (GMA, Philstar, Manila Bulletin)
